# E-Commerce API

This is the solution for Assignment 07: E-Commerce Product & Shopping Cart API using File-System storage.

## Setup
1. Run `npm install`
2. Create `.env` from `.env.example`
3. Start the server with `npm run dev`

## Notes
- Products are stored in `data/products.json`
- Users are stored in `data/users.json`
- Carts are stored in `data/carts.json`
- Use an API client like Postman or ThunderClient to interact with the API. Note that this API uses cookies for session management, so ensure your client is set up to preserve cookies between requests.
